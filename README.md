# Overview: Telegram Bot with Gemini AI for Company Information Retrieval

This project implements a Telegram bot that utilizes the Gemini AI model to provide information about a company. The bot processes various file types (PDF, JSON, HTML, CSV, Excel) to build a comprehensive knowledge base. Users can interact with the bot by sending text messages or images, and the bot will respond with relevant information retrieved from the loaded data or generated by Gemini.

## Features

✅ **Gemini AI Integration:** Uses Google's Gemini AI model to understand user queries and generate responses.

✅ **Image Processing:** Can analyze images and provide descriptions or answer questions related to the images.

✅ **Intent Matching:** Optionally matches user queries with predefined intents for quick responses.

✅ **Conversation Logging:** Logs all user interactions and bot responses to an Excel file.

✅ **Admin Alerts:** Sends alert messages to a designated admin user for specific events.

✅ **Markdown Support:** Supports MarkdownV2 formatting in bot responses.

✅ **File Handling:** Handles various file types and encodings.

## Requirements

-   Python 3.6+
-   `requests`
-   `google-generativeai`
-   `beautifulsoup4`
-   `pandas`
-   `openpyxl` (for Excel support)
-   `pypdf2` (for PDF support)
-   `python-dotenv` (optional, for environment variables)
